# Password Manager

## Description
A simple Python program that generates a random 12-character password for a website and stores it in a text file.

## Features
- Generate secure random passwords
- Save website names with passwords
- Automatically appends new entries
- Uses letters and digits

## Technologies Used
- Python 3
- random
- string

## How to Run

```bash
python main.py
```

```

Generated Password: aB7xK9LmP2Qz
Password Saved!
```
